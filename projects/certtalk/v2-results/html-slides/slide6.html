Our Approach: Implementation & Evaluation

How we'll build and test the system

1. What We'll Implement

CertTalk Protocol:

  • PATH & CUT certificate encodings
  • Witness bit negotiation
  • Oracle verification module

Baseline Systems:

  • Send-All (raw coordinates)
  • Other exploration strategies

2. Dataset & Testing

  • Generate 1,000 cached grids (4×4 to 22×22, varied density 5%-30%)
  • Mix reachable and unreachable scenarios for comprehensive coverage
  • Run all systems under identical constraints (64 msg, 256 bytes/packet)
  • Oracle validates final artifacts against union map

3. Metrics & Why We Measure Them

✓ Correctness: Oracle acceptance rate → Validates certificates work

✓ Efficiency: Bytes + messages per conversation → Ensures practical overhead

✓ Interpretability: Human verification time → Tests auditability feasibility
